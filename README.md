# 3D Transformation Showcase

A premium, interactive 3D demonstration powered by **Three.js**. Explore various geometric transformations in a real-time, nebula-themed environment.

## 🚀 Live Demo
**View the website here:** [https://utsav-a11y.github.io/3d-website/](https://utsav-a11y.github.io/3d-website/)

## ✨ Features
- **Dynamic Object Selection**: Switch between Torus Knot, Cube, Sphere, and Dodecahedron.
- **Pulsing Neon Material**: Objects feature a "breathing" emissive glow.
- **Real-time Controls**: Adjust rotation speed, scale, and colors on the fly.
- **Interactive Camera**: Orbit and zoom using your mouse/touch.
- **Deep Space Aesthetics**: Animated nebula clouds and a procedural starfield.

## 🛠️ Tech Stack
- **Three.js**: 3D Engine
- **HTML5/CSS3**: Structure and premium Glassmorphism UI
- **JavaScript (ES6)**: Logic and interactivity

## 💻 Local Setup
1. Clone the repository.
2. Run `python run.py` (or double-click `start_project.bat`).
3. Open `http://localhost:8000` in your browser.
